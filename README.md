# 栏栏菜谱 · LanLan Menu

一个超可爱的个人菜谱小站，用来记录喜欢的荤菜、素菜和主食。

🔗 在线访问：**https://raychan611.github.io/LanLan-Menu/**

## 特点

- 🍳 分类浏览：荤菜 / 素菜 / 主食
- 🎨 温暖可爱的配色，圆角卡片 + 柔和阴影
- 📱 响应式设计，手机和电脑都能看
- 🖼️ 首页背景使用专属插画
- 📷 每道菜配有统一风格的高质感餐厅摄影图
- 👆 点击卡片弹出详细食材与做法
- 🥣 破壁机早餐：逐项浸泡安排、营养特点、注意事项及参考来源，可搜索“早餐”或“破壁机”

## 如何添加新菜谱

编辑 [`recipes.json`](recipes.json) 中的 `recipes` 数组，按现有格式添加即可。它是菜谱数据的唯一来源，也会被“栏栏日常”自动同步；请保持每道菜的 `id` 唯一且不要复用已经发布过的编号。

每道菜的 `image` 字段指向对应图片，菜谱照片统一存放在 `assets/recipes/`，当前使用 1200×800 的 JPEG 文件以兼顾清晰度和加载速度。新增或修改菜谱后，先确认 JSON 语法正确，再一起提交菜谱数据和图片。

### 早餐详情数据

菜谱仍使用版本 1 的核心字段；早餐新增的字段均为可选，原有菜谱无需补填：

- `tags`：可搜索的标签，例如“早餐”“破壁机”。早餐仍归入“主食”，不新增分类。
- `soaking`：浸泡条目，每项包含食材 `ingredient`、时间 `duration` 与说明 `note`。
- `benefits`、`notes`：营养特点及注意事项的文字列表。
- `servings`、`sources`：份量说明与参考来源（每项含 `title`、`url`，网页只展示 HTTPS 链接）。
- `guide`：引用顶层 `guides` 中的共用说明。页面加载时补充份量，并把共用注意事项、来源接在该菜谱自己的内容后。其他同步方如需显示这些新增详情，应使用相同的合并规则；核心 `ingredients`、`steps`、`tip` 仍可单独使用。

六套破壁机配方均保留原图的 80 克干料比例，先称重再浸泡。尚未指定机器型号与热饮容量，因此不写死加水毫升数或程序分钟数；制作前须按说明书的单次干料量等比例缩放，并核对热饮水位与生豆加热要求。营养文字不作治病、祛湿或降糖承诺。照片是生成的成品示意，并非这套配方的实拍或实测结果。

### 本地检查

项目没有构建步骤和运行依赖。安装支持内置测试工具的 Node.js 后，可在项目根目录执行：

```sh
node --check script.js
node --test tests/recipes.test.cjs
```

检查包含编号唯一性、图片是否存在、六套干料配比、浸泡食材覆盖及安全说明完整性。页面涉及读取 JSON，预览应通过本地 HTTP 服务打开，不要直接双击 HTML 文件；还需人工确认手机与电脑上的详情布局、搜索及收藏。

## 技术

纯静态页面：HTML + CSS + JavaScript，部署在 GitHub Pages。页面和“栏栏日常”共用公开的 [`recipes.json`](recipes.json)，不需要额外数据库或付费接口。
