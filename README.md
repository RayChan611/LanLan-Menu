# 栏栏菜谱 · LanLan Menu

一个超可爱的个人菜谱小站，用来记录喜欢的家常菜、早餐、汤羹、甜品和小食。

🔗 在线访问：**https://raychan611.github.io/LanLan-Menu/**

## 特点

- 🍳 分类浏览：家常菜 / 早餐 / 汤羹 / 甜品 / 小食
- 🎨 温暖可爱的配色，圆角卡片 + 柔和阴影
- 📱 响应式设计，手机和电脑都能看
- 🖼️ 首页背景使用专属插画
- 👆 点击卡片弹出详细食材与做法

## 如何添加新菜谱

编辑 [`script.js`](script.js) 中的 `recipes` 数组，按现有格式添加即可。

## 技术

纯静态页面：HTML + CSS + JavaScript，部署在 GitHub Pages。
